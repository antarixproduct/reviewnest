# Changelog

## 1.0.0 - Initial ReviewNest Release

- Converted the previous multi-business flow into single-business ReviewNest setup.
- Added one-time setup screen.
- Locked registration after setup.
- Kept sign-in-only owner access after setup.
- Kept MongoDB Atlas and Mongoose database layer.
- Added customer management with optional email.
- Added manual WhatsApp review request generation.
- Added optional Gmail SMTP email automation.
- Added review gateway with configurable Google redirect threshold.
- Added private feedback inbox.
- Added tracking dashboard.
- Added PWA manifest and service worker generation.
- Removed admin panel assumptions, plan gating, payment processing, push notifications, Google Places sync, OTP signup, and third-party email API dependency.
