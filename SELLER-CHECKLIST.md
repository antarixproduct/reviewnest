# Seller Checklist

Before sending this package to a customer:

- Confirm no `.env` files are included.
- Confirm no `node_modules` folders are included.
- Confirm no `dist` build output is included unless intentionally selling a built static artifact.
- Confirm no MongoDB URI, Gmail password, JWT secret, or API key is included.
- Confirm `LICENSE.txt` is included.
- Confirm `.env.example`, `server/.env.example`, and `dashboard/.env.example` are included.
- Confirm `README.md`, `SETUP-GUIDE.md`, `SUPPORT.md`, and `CHANGELOG.md` are included.
- Zip the clean `ReviewNest-v1.0.0` folder.

Recommended product listing:

ReviewNest is a self-hosted review request system for one business. It includes a PWA-ready React dashboard, Node/Express backend, MongoDB Atlas support, WhatsApp review requests, private feedback capture, customer tracking, and optional Gmail SMTP automation.
